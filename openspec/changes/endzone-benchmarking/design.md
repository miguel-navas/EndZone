# Design
Extend /comparacoes with Benchmarking mode. Select target franchise, inclusive NFL seasons, phase, cohort and weighting (game-weighted default or equal-franchise). History requires separate reference season range. Conference/division membership evaluated per season; champions cohort uses Super Bowl winners in each selected season. Exclude target from peer cohorts, not from own history. Peer games include games against target. Use same phase and metric definition for target and reference. Default excludes preseason; playoffs includes Super Bowl exactly once.
GET /api/comparisons/benchmarks with franchiseId, fromSeason, toSeason, phase, cohort, weighting, optional referenceFromSeason/referenceToSeason. Return target and reference rates, observed games, eligible games, peer count, absolute delta, relative delta (null if reference zero), coverage, sources, revision and asOf. Win rate=(wins+0.5*ties)/games. For metric m, weighted rate=sum(m)/observed games; equal-franchise rate=mean of each eligible franchise rate. Missing values excluded from observed denominator, never zero-filled. No eligible peers returns null reference. Rank by normalized metric with documented direction, ties share rank; disclose coverage threshold. Annual trends use same rules per season; records require explicit scope and coverage. No AI arithmetic. SQL query repository uses canonical facts and historical memberships, optional projections after benchmark. Invalidate on fact, membership or title corrections. UI displays method, sample size, partial coverage, loading/error/empty states, keyboard-accessible controls and charts.
