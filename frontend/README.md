# END ZONE — Frontend

Aplicação React + TypeScript + Vite para a homepage v0.5.

## Executar

```bash
cd frontend
npm install
npm run dev
```

Para verificar o build: `npm run build`.

## Status
- Cabeçalho fixo, sidebar responsiva e ícones Lucide.
- Home com seções de jogos, classificação, notícias e equipes.
- Sem dados fictícios de partidas.
- Pendências: assets originais, homologação visual, integração NFL e testes automatizados.

A pasta `prototype/` mantém a referência HTML anterior. Não substitua os assets aprovados por fotografias genéricas.
