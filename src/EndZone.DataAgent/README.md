# EndZone Data Agent
Initial staging worker. Requires .NET 10 SDK and PostgreSQL. Apply database/migrations/001_ingestion.sql, set ConnectionStrings__EndZone securely, configure approved CSV URLs in Ingestion:Datasets, then run `dotnet run --project src/EndZone.DataAgent`. Historical datasets can be configured separately by season; incremental datasets are checked every PollMinutes. Identical content is deduplicated, failures retried next cycle. Run a single worker instance initially. No domain normalization, AI implementation, live scores or deployed scheduling yet. Verify dataset schemas and redistribution rights before configuring URLs. Never commit credentials.
